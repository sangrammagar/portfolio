# Sangram Magar — Portfolio Website

## Preview locally
1. Extract the ZIP (if downloaded).
2. Open `index.html` in a modern browser.

## Publish online
- **GitHub Pages:** Create a repository, upload `index.html` and the `assets/` folder, then enable Pages in repository Settings.
- **Netlify:** Drag the extracted `sangram_portfolio` folder into Netlify Drop.
- **Vercel:** Import the GitHub repository as a static site.

## Personal details
The page uses the supplied portrait and resume information. Please verify contact details and project links before publishing.
